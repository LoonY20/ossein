# Code of Conduct

Ossein is intended to be a welcoming, technical, and constructive open-source project.

## Our standards

Participants are expected to:

- be respectful and professional;
- discuss ideas and code without attacking people;
- give actionable, technical feedback;
- assume good intent while still addressing harmful behavior clearly;
- respect different experience levels and backgrounds;
- keep discussions relevant to the project.

Unacceptable behavior includes harassment, discrimination, personal attacks, threats, deliberate disruption, publishing private information, and other conduct that makes participation unsafe or hostile.

## Enforcement

Maintainers may edit or remove comments, issues, pull requests, code, or other contributions that violate these standards. Repeated or serious violations may result in temporary or permanent restrictions from project spaces.

To report conduct concerns, contact the repository maintainer privately through GitHub rather than opening a public issue containing sensitive details.

## Scope

This code of conduct applies to project spaces and to public interactions where someone is representing the Ossein project.
