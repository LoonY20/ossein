# Security Policy

Ossein is currently in an early development stage and is not ready for production use.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability reporting feature when it is available for this repository. If private reporting is not available, contact the repository owner privately through GitHub before sharing technical details publicly.

When reporting a vulnerability, include enough information to reproduce and understand the issue:

- affected version or commit;
- affected component;
- reproduction steps or proof of concept;
- expected and actual behavior;
- potential impact;
- any mitigation you have identified.

## Supported versions

Until Ossein reaches its first stable release, security fixes are applied to the latest development version only.

## Disclosure

Please allow maintainers reasonable time to investigate and prepare a fix before public disclosure.
