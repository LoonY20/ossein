# Ossein v0.1.0

Ossein v0.1.0 is the first public release.

It establishes the framework's central rule:

> Laravel-inspired developer experience. Idiomatic Go underneath.

## Highlights

### HTTP core

- standard-library `net/http` application, routing, groups, and middleware;
- error-returning handlers with structured JSON errors;
- strict JSON binding with Content-Type validation and a configurable body
  size limit;
- explicit request validation with field-level error responses;
- request IDs, request-scoped `log/slog` loggers, and response status and
  size tracking;
- route conflicts reported as startup errors before the server accepts
  traffic;
- lifecycle hooks and graceful shutdown;
- named routes, URL generation, and route inspection.

### Application structure

- constructor-based dependency injection with interface bindings;
- singleton and transient lifetimes with graph validation;
- typed environment configuration and dependency-free `.env` loading.

### Data workflow

- driver-neutral `database/sql` configuration, pool management, lifecycle,
  and dependency injection;
- PostgreSQL, MySQL, and SQLite migration dialects;
- transactional filesystem or embedded migrations with up, rollback, and
  status operations;
- PostgreSQL advisory locks and MySQL named locks that serialize migration
  runners across processes, with configurable lock timeouts;
- `database.WithinTransaction` with rollback, panic safety, and explicit
  `*sql.TxOptions`;
- ordered transactional seeders;
- generic, concurrency-safe test factories with states and persistence hooks;
- composed `data.Commands` wiring for migrations and seeders.

### Developer CLI

- `ossein new` starter with typed configuration and a tested health endpoint;
- supervised `ossein dev` hot reload with build-error recovery;
- `ossein routes`, application-owned migration commands, and `ossein db:seed`;
- controller, middleware, and request generators.

Ossein has no third-party runtime dependencies. Applications compile only the
database drivers they choose.

## Install

Install the CLI:

```bash
go install github.com/LoonY20/ossein/cmd/ossein@v0.1.0
```

Add the framework to an existing Go module:

```bash
go get github.com/LoonY20/ossein@v0.1.0
```

Or create a new application:

```bash
ossein new hello-ossein
cd hello-ossein
go mod tidy
ossein dev
```

## Quality

- CI runs formatting, vet, CLI builds, and the full race detector;
- CI enforces at least 85% total statement coverage;
- PostgreSQL 17 and MySQL run as real CI services with concurrency tests;
- the generated starter is compiled and tested end to end;
- the CRUD example exercises the public API through HTTP integration tests.

## Stability

This is a pre-1.0 release. Public APIs may evolve as Ossein is validated in
real applications. Production use should be evaluated carefully.

- SQLite currently has only the in-process runner lock and should use a
  single migration job;
- see the [roadmap](../ROADMAP.md) for planned production modules.
